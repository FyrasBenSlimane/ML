# Emna : anticiper le traitement antidiabétique à l'hôpital

Dataset : *Diabetes 130-US hospitals* (`diabetic_data.csv`).

Deux questions posées dès l'admission, à partir du profil clinique du patient :
1. Son traitement antidiabétique va-t-il être **modifié** pendant le séjour ?
2. Aura-t-il besoin d'**insuline** ?
