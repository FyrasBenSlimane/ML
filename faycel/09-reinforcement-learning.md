# 9. Politique de traitement optimale par Reinforcement Learning

## Objectif métier
Apprendre automatiquement la meilleure stratégie d'ajustement médicamenteux pour minimiser le risque de réadmission, l'IA "décide" une action au lieu de simplement prédire un risque.

## Objectif data
Offline Reinforcement Learning (ex. Q-Learning à partir de données historiques) où l'état = profil patient, l'action = ajustement médicament, la récompense = non-réadmission.
